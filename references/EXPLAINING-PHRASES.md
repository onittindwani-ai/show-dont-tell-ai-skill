# Explaining Phrases: What to Cut and What to Write Instead

An explaining phrase describes the business instead of showing a result. Readers skip them because every competitor uses the same ones.

**The swap test:** could a competitor paste this line on their own site and it would still be true? If yes, it's explaining. Rewrite it until only this business could say it.

**The fix pattern:** replace the adjective with the fact that would make someone use that adjective.

## 1. Talking about yourself instead of the customer

| Cut | Why it fails | Write instead |
| --- | --- | --- |
| Welcome to [name] | Wastes the most valuable line | The customer's result |
| We are a [type of company] | Category, not value | What the customer gets from you |
| We offer / We provide | About you | "You get..." |
| Our mission is to... | Nobody reads missions | What a customer experienced |
| We believe in... | A feeling, not proof | The habit that belief produces ("Every quote is fixed, no surprises") |
| We pride ourselves on... | Self praise | A customer's words saying it |
| Our team of experts | Claimed | Who they are, how many years, how many jobs (real) |
| With over X years of experience | Fine only with a result attached | "12 years, 400 kitchens fitted" |
| Founded in [year] | History, not value | Move it to the About page |

## 2. Empty quality words

| Cut | Write instead |
| --- | --- |
| High quality / premium quality | The material, check or warranty that makes it quality |
| Best / the best / best in class | A real ranking, award or rating, or drop it |
| World class / leading / industry leading | A count or recognition you can show |
| Excellent / outstanding / exceptional | A review saying it, in the customer's words |
| Professional | What professional looks like: on time, written quote, clean site |
| Reliable / dependable | The proof: "On time for 96% of jobs last year" (only if real) |
| Trusted | Who trusts you, how many, for how long |
| Top notch / top rated | The actual rating and number of reviews |
| Unmatched / unparalleled | Delete |

## 3. Vague service words

| Cut | Write instead |
| --- | --- |
| Solutions | The plain name of what you do |
| One stop shop / one stop solution | The 3 things the customer no longer has to arrange |
| End to end / full service | The steps you handle, listed |
| Wide range of services | The 3 services people actually buy most |
| Tailored / bespoke / customised solutions | One example of how it changed for one customer |
| Comprehensive | What is included, specifically |
| Holistic | Delete |
| Value added services | Name the service |

## 4. Fake easy words

| Cut | Write instead |
| --- | --- |
| Seamless | The steps: "1 call, 1 form, done in 3 days" |
| Hassle free / stress free | The hassle you remove: "We handle the permits" |
| Effortless | What the customer does (very little): "You send photos, we do the rest" |
| Convenient | The convenience: "Open till 10 pm, 7 days" |
| Easy to use | "Set up in 10 minutes, no training" (if true) |
| Quick / fast | The time: "Delivered in 2 days" |

## 5. Tech and buzzwords

| Cut | Write instead |
| --- | --- |
| Innovative / cutting edge / next generation | What it lets the customer do that they couldn't before |
| State of the art | The one feature that matters and why |
| AI powered / smart | What happens automatically for the customer |
| Leverage | Use |
| Synergy | Delete |
| Empower | Help, let |
| Streamline / optimise | The time or steps saved |
| Robust / scalable | What it handles: "Works the same at 10 orders or 10,000" |
| Disruptive / revolutionary | Delete |
| Data driven | The number you track and report |

## 6. Customer words without proof

| Cut | Write instead |
| --- | --- |
| Customer first / customer centric | A real habit: "We answer every message within 2 hours" |
| Passionate about | What the passion produced: a result, a review |
| We care about our customers | What you do that shows care |
| Satisfaction guaranteed | The exact guarantee and terms, only if real |
| Personal touch | The personal thing: "The owner checks every order" |
| Trusted by many / loved by thousands | The real number, or a real review |

## 7. Price words

| Cut | Write instead |
| --- | --- |
| Affordable / budget friendly | The price, or "from X" |
| Competitive prices / best prices | The price and what's included, or a fair comparison you can back up |
| Great value | What they get for the price |
| Premium pricing (as a defence) | The result that justifies it |
| Call for pricing (with no reason) | A starting price or range, or why it varies |

## 8. Weak endings

| Cut | Write instead |
| --- | --- |
| Feel free to contact us | One specific action |
| Don't hesitate to reach out | One specific action |
| Contact us for more information | "Book a 15 minute call: you'll get a price and a date" |
| Let us know if you have any questions | A question they can answer in 1 word |
| Please share your requirement | Ask for the 1 or 2 details you need: "Send a photo and your area" |
| Looking forward to hearing from you | A specific ask with a time |
| Visit our website (in an email) | The link to the exact page, with why |
| Call, email or WhatsApp us | Pick one |

## 9. Filler openings (emails and DMs)

| Cut | Write instead |
| --- | --- |
| I hope this email finds you well | Start with their problem or your result |
| My name is X and I work at Y | Put your name in the signature |
| I wanted to reach out because | Say the reason directly |
| Just following up | A new reason to reply: a new idea, a result, a deadline |
| Sorry to bother you | Delete; be useful instead |
| Thank you for contacting us (as the whole first line) | Answer their question first |

## Quick self test

Read the first 3 lines of any text. Count:

- Lines a competitor could copy unchanged: target 0.
- Adjectives with no fact behind them: target 0.
- Times "we" or "our" appears before the first "you": target 0.
