# Explaining Phrases (and what to write instead)

These phrases describe a business instead of showing a result. Readers skip them. Replace each one with something the customer can see, count or feel.

| Explaining phrase | Why it fails | Show it instead (pattern) |
| --- | --- | --- |
| We offer / We provide | Talks about you, not the customer | Start with what the customer gets: "You get..." |
| High quality | Everyone says it | A specific detail: materials, checks, a warranty you really give |
| Best in class / world class / leading | Nobody can check it | A ranking, award or count, only if real |
| One stop solution / end to end | Vague | Name the 3 things they no longer need to do |
| Customer first / customer centric | A promise with no picture | A real habit: "We answer every message within 2 hours" |
| Passionate about | About your feelings | What the passion produces: a result, a review |
| Innovative / cutting edge / next generation | Empty | What it lets them do that they couldn't before |
| Tailored / bespoke / customised solutions | Says nothing | Show one example of how it changed for one client |
| Seamless / hassle free | Claimed, not shown | The steps: "1 call, 1 form, done in 3 days" |
| Years of experience | Needs a number and a result | "12 years, 400 kitchens fitted" (only if true) |
| Trusted by many | Vague proof | The real number or names, with permission |
| Affordable / competitive prices | Every business says it | The actual price or a comparison you can back up |
| We help businesses grow | Too broad | Which business, which number goes up, by how much |
| Feel free to contact us for more information | A weak ending | One action: "Book a 15 minute call" |
| Don't hesitate to reach out | A weak ending | One action, with what happens next |
| State of the art | Empty | The one feature that matters, and why |
| Solutions | Hides what you do | The plain name of the thing you do |
| Leverage / synergy / empower | Jargon | A plain verb: use, combine, help |

## Quick test

Read a line and ask: **could a competitor paste this line on their site and it would still be true?** If yes, it's explaining. Rewrite it until only this business could say it.
